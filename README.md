## Isi repositori
- `tugas_UTS.ipynb`: pengerjaan Linear Regression, Logistic Regression, evaluasi, eksperimen, dan bonus.
- `Ads_Data.csv`: dataset biaya iklan dan penjualan (40 baris).
- `Email_Data.csv`: dataset klasifikasi email spam (60 baris).

## Ringkasan
Notebook mengimplementasikan split data, Linear Regression dengan Normal Equation, Linear Regression dengan Gradient Descent, Logistic Regression dengan Gradient Descent, serta metrik evaluasi menggunakan NumPy. Nilai R², RMSE, accuracy, precision, recall, F1-score, dan hasil eksperimen dapat dilihat setelah menjalankan notebook dari awal sampai akhir.

## Menjalankan notebook
Letakkan ketiga file di folder yang sama, buka `tugas_UTS.ipynb`, lalu pilih **Run All**. Bagian bonus membutuhkan `scikit-learn`.
